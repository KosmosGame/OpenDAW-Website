OpenDAW

OpenDAW is a free, open-source digital audio workstation made with Python.

Get OpenDAW

Download the Windows version, extract it, and open OpenDAW.exe.

Download OpenDAW

GitHub

OpenDAW on GitHub

Running from source

Install Python, then open a terminal in the OpenDAW folder.

pip install -r requirements.txt
python run.py

Windows build

If you are building the program yourself:

Set-ExecutionPolicy -Scope Process Bypass
